# 🏥 Hospital Dashboard

Hospital Dashboard is a full-stack web application developed to explore and understand real-world healthcare management systems.  
The project focuses on building a responsive dashboard interface with proper frontend and backend integration.

This project was mainly created for learning purposes to improve practical full-stack development skills and deployment experience.

---

## 🚀 Live Deployment

### Frontend Deployment
Deployed using **Vercel**

### Backend Deployment
Deployed using **Render**

---

## ✨ Features

- 🔐 User Authentication

- 📊 Hospital Management Interface
